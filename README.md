# NorthAmericanTimeZones
This is a browser-based graphical clock that shows the current time in all Canadian and US time zones

With many Canadian Provinces and Territories having their own time zone, this clock outlines each one and shows their local time in an easy to see format.

Use and modify to suit your needs.

To use simply load the .html file in your favourite browser.
