# NorthAmericanTimeZones
This is a browser-based graphical clock that shows the current time in all Canadian and US time zones

With many Canadian Provinces and Territories having their own time zone, this clock outlines each one and shows their local time in an easy to see format.

Use and modify to suit your needs.

To use simply load the .html file in your favourite browser.

## Standalone edition (v1.6)

The page is now fully self-contained: the map data and libraries are built into the one HTML file, so it runs with no internet connection on Windows, macOS, Linux or a Raspberry Pi. It also adds:

- Full-width map that scales to any screen
- UTC clock, plus a "home" clock for your own zone (auto-detected or chosen in Settings), outlined in gold on the map
- Kiosk mode for a shack display: press K (or the Kiosk button); F for full screen, Esc to exit
- 12-hour option alongside 24-hour
- Mexico, plus Puerto Rico and the US Virgin Islands on the map
- "+1 day" / "−1 day" markers where the date differs from yours (handy for Guam)
- Settings for theme, font and text sizes; URL options such as `?kiosk=1` for dedicated displays

Standalone edition by Tom Salzer, KJ7T. The editable source and build script are in the `source` folder; see `source/README.md`.
